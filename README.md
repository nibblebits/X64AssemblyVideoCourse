## 📝 Course Overview

In this course you will learn:

### ✔️ 64-bit CPU architecture & registers  
### ✔️ Writing real NASM assembly programs  
### ✔️ Calling C functions from assembly  
### ✔️ Working with the SysV ABI calling convention  
### ✔️ Stack frames and calling conventions  
### ✔️ Debugging assembly with GDB  
### ✔️ Handling strings, loops, pointers, and memory  
### ✔️ Building full programs mixing C + assembly  
### ✔️ Compiling & linking with GCC / LD  
### ✔️ Real-world 64-bit software development

By the end, you’ll know how to write fully-functional x86-64 binaries and integrate them cleanly with C code.
